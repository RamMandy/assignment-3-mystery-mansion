# 🏰 Mystery Mansion – The Vanishing Diamond

**Futuregames | Frontend Programming – Assignment 3**

## About the Game

Mystery Mansion is an interactive detective game created using HTML, CSS, and JavaScript.

A valuable diamond has disappeared from Blackwood Mansion. The player must explore rooms, collect clues, and identify the thief.

## How to Play

1. Enter your name and start the game.
2. Meet the three suspects.
3. Explore different rooms and investigate clues.
4. You have 5 moves to investigate.
5. Review your clues in the Evidence Journal.
6. Accuse the suspect you believe is the thief.

## Features

- Interactive storyline and choices
- Clue collection and move counter
- Multiple winning and losing outcomes
- Sound effects
- Play Again option
- Responsive design for mobile and desktop

## Technologies Used

- HTML5
- CSS3
- Vanilla JavaScript

## JavaScript Concepts Used

- Variables, arrays, and objects
- Conditional statements
- Functions and event listeners
- DOM manipulation (`createElement`, `appendChild`, `remove`)
- CSS class manipulation (`classList`)
- Dynamic content updates (`textContent`)
